Prüfanfrage

EUDI-Wallet-Prüfung mit simulierter Wallet. Ein Klick startet den vollständigen Prüfpfad.

DEMO – bitte nicht für echte Daten verwenden
  • Nur TEST-Material: Schlüssel, Zertifikate und Trust List werden beim Start im Arbeitsspeicher erzeugt.
  • Entwicklungsbetrieb: ATTACK_DEV_MODE=true, selbstsigniertes Verifier-Zertifikat.
  • Keine echte Wallet nötig – eine simulierte Wallet legt den Nachweis selbst vor.
  • Alles bleibt auf diesem Rechner (127.0.0.1). Keine Sandbox, keine Behörde, kein Server im Internet.
